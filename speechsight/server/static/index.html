SpeechSight AI System Architecture

Android + Python AI Core

📱 Android Client Stack

  • Language: Kotlin
  • UI Framework: Jetpack Compose (Material 3)
  • Camera: CameraX with Lip Framing Guide Overlay
  • Video Playback: Android Media3 ExoPlayer
  • Local Database: Room Database (Encrypted Entity Storage)
  • Background Jobs: WorkManager for background jobs
  • Mobile Inference: TFLite & ONNX Runtime Mobile

🧠 AI & Computer Vision Pipeline

  • Face Detection: MediaPipe Face Landmarker / OpenCV
  • Face Tracking: Persistent spatial IoU & identity tracking
  • Mouth ROI: Normalized 96x96 CLAHE-equalized lip sequences
  • Visual Speech: Spatiotemporal 3D Conv + Transformer (AV-HuBERT / Auto-AVSR)
  • Multimodal Fusion: Dynamic SNR-weighted cross-modal attention
  • Confidence Calibration: ECE calibrated tri-score breakdown

🔒 Privacy & Safety Controls

  • Local Processing: Prioritizes on-device processing
  • Ephemeral Storage: Automatic zero-trace deletion of crops
  • Uncertainty Indicators: Explicit warnings for visual-only predictions
  • Consent & Privacy: Zero covert recording or facial identity harvesting
  • Export Subtitles: Standard SRT, WebVTT, Plain Text, JSON

Android Room DB & Media3 ExoPlayer Architecture

// Android Jetpack Compose + Room + Media3 Architecture
@Entity(tableName = "transcripts")
data class TranscriptEntity(
    @PrimaryKey val id: String,
    val videoUri: String,
    val language: String,
    val processingMode: String,
    val createdAt: Long = System.currentTimeMillis()
)

@Composable
fun SpeechSightPlayerView(
    videoUri: Uri,
    segments: List<TranscriptSegment>,
    onSeekTo: (Long) -> Unit
) {
    val exoPlayer = rememberExoPlayer(LocalContext.current)
    AndroidView(factory = { ctx ->
        PlayerView(ctx).apply { player = exoPlayer }
    })
    LipLandmarkCanvasOverlay(landmarks = currentFrameLandmarks)
}
